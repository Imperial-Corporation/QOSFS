# QOSFS

**QOSFS** (Quick Optimized Stable File System) is a lightweight, simple and experimental file system designed for Imperial NextOS.

> [!WARNING]
> QOSFS is under active development and is **not ready for production use**. Features may be incomplete, unstable or subject to change. Do not use it to store important data.

## About QOSFS

QOSFS aims to provide a simple file system with the features necessary for everyday file operations, while exploring opportunities for optimization.

Rather than aiming to be a huge and complex file system, QOSFS focuses on simplicity, lightweight design and useful features.

The name QOSFS stands for:

* **Q**uick
* **O**ptimized
* **S**table
* **F**ile
* **S**ystem

Stability and performance are project goals, not guarantees at its current experimental stage.

## Compatibility

QOSFS is being developed for **Imperial NextOS**, where it is intended to be supported alongside FatFs.

For now, FatFs is the recommended option for more reliable file system operations.

* [FatFs official website](https://elm-chan.org/fsw/ff/)
